# 岁时记 · 二十四节气 | 非遗文化沉浸式体验网站

以二十四节气为主题的中国非遗文化展示页面，集图文展示、交互浏览、沉浸体验于一体，呈现从立春到大寒的完整节气轮回。

## 项目预览

- **页面标题**：岁时记·二十四节气 | 非遗文化沉浸式体验
- **技术栈**：HTML5 + CSS3 + 原生 JavaScript（零外部依赖）
- **页面架构**：单页应用，内联样式与脚本

## 目录结构

```
/
├── website.html              # 主页面（含全部 HTML/CSS/JS）
├── README.md
├── content/
│   └── 文案.txt               # 二十四节气完整文案素材
├── image/                     # 节气主图（24张国风插画 PNG）
├── backgrounds/               # 节气背景图（24张氛围实景 JPG）
└── custom-image/              # 非遗习俗实景图（22张 JPG）
```

## 功能特性

- **Hero 全屏视差区** — 背景图固定视差、渐变遮罩、滚动淡出
- **24 节气完整展示** — 节气名称、日期范围、物候描述、习俗标签
- **全屏沉浸阅览** — 点击节气卡片进入全屏模式，支持左右切换、键盘导航、缩略图跳转
- **非遗名录 3D 弹性展开** — 横向竖块布局，悬停时展开并呈现 3D 视差效果
- **花信风物候文化** — 12 项节气三候信息展示
- **详情模态框** — 节气完整文案、古诗与习俗
- **滚动入场动画** — IntersectionObserver 驱动的元素渐入效果
- **响应式布局** — 适配手机、平板、桌面端

## 页面布局

```
Hero 全屏首屏
  ↓
节气总说（引言）
  ↓
四季展示卡片（立春 · 立夏 · 立秋 · 立冬）
  ↓
24 节气网格卡片（点击进入全屏沉浸模式）
  ↓
非遗名录活态传承（横向弹性竖块）
  ↓
花信风物候文化（节气三候）
  ↓
页脚 · 返回顶部
```

## 交互操作

| 操作 | 效果 |
|------|------|
| 滚动页面 | 元素渐入动画、Hero 淡出 |
| 点击节气卡片 | 打开全屏沉浸式展示 |
| 全屏模式下 ← → 点击 | 切换上一个/下一个节气 |
| 全屏模式下键盘 ← → | 切换节气 |
| 全屏模式下 Esc | 关闭全屏 |
| 全屏模式下悬停顶部 | 展开节气缩略导航 |
| 悬停非遗竖块 | 3D 展开 + 详情滑出 |
| 点击返回顶部按钮 | 平滑滚动至页首 |

## 数据说明

24 节气数据包含以下字段：
- 名称、日期范围、所属季节
- 物候短描述、习俗说明
- 完整节气文案、关联古诗词

非遗名录涵盖 11 项与节气相关的非遗项目：
九华立春祭、班春劝农、石阡说春、苗族赶秋、安仁赶分社、壮族霜降节、三门祭冬、半山立夏习俗、送大暑船、梅源芒种开犁节、内乡打春牛习俗

## 配色方案

以大地色系为主调：米白宣纸色背景、深赭石色文字、琥珀金装饰、栗色标题，整体低饱和度温润质感。

## 开发说明

所有资源均为本地部署，无外部 CDN 依赖，可直接在浏览器中打开 `website.html` 运行。

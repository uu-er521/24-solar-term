# 岁时记 · 二十四节气 | 非遗文化沉浸式体验网站

以二十四节气为主题的中国非物质文化遗产沉浸式展示页面，集图文展示、交互浏览、沉浸体验于一体，呈现从 **立春** 至 **大寒** 的完整节气轮回。

> 二十四节气于 2016 年被列入联合国教科文组织人类非物质文化遗产代表作名录。

## 项目预览

- **页面标题**：岁时记·二十四节气 | 非遗文化沉浸式体验
- **技术栈**：HTML5 + CSS3 + 原生 JavaScript（零外部依赖、无框架、纯静态）
- **页面架构**：单页应用，HTML/CSS/JS 全部内联于 `index.html`
- **设计主题**：中国风 · 大地色系 · 宣纸质感 · 低饱和度温润美学
- **团队署名**：第一队

## 功能特性

### 🎨 视觉与交互

| 特性 | 说明 |
|------|------|
| **Hero 全屏视差区** | 背景图固定 `background-attachment: fixed` 实现视差效果，搭配渐变遮罩层，滚动时渐隐淡出 |
| **24 节气网格卡片** | JavaScript 动态渲染，每张卡片展示节气名称、日期范围、物候短述、习俗标签与季节图标 |
| **全屏沉浸阅览** | 点击节气卡片进入全屏模式，以深色质感背景呈现节气完整文案，支持左右切换、键盘导航、缩略图跳转 |
| **缩略图导航条** | 全屏模式下悬停顶部展开，24 张节气缩略图横向排列，点击快速跳转 |
| **四季展示卡片** | 立春 · 立夏 · 立秋 · 立冬 四张横排大卡，图文并茂概览四季开端 |
| **非遗名录 3D 弹性展开** | 横向弹性滚动竖块布局，每项含双图层图片（主图 + 悬停切换图），悬停时 3D 展开并呈现详情文字 |
| **花信风物候文化** | 24 组节气三候信息（七十二候）以网格卡片展示，每候配有对应风格 emoji |
| **节气钟 · 实时钟面** | 以 `节气钟.jpg` 为背景的仿古装饰组件，集成实时数字时钟、当前日期显示、当前节气自动识别与显示 |
| **留言板** | 页面底部留言交互区域，用户可输入内容留言（前端交互演示） |
| **滚动入场动画** | 基于 IntersectionObserver API，元素滚动进入视口时触发渐入上移动画 |
| **返回顶部按钮** | 固定于页面右下角，点击平滑滚动至页首 |

### 📱 响应式布局

- 适配 **手机、平板、桌面端** 多种屏幕尺寸
- 节气网格：桌面端 4 列 → 平板 3 列 → 手机 2 列
- 花信风网格：桌面端 6 列 → 平板 4 列 → 手机 2 列
- 节气钟组件在移动端自动缩小字号与间距

## 节气数据说明

24 节气数据（定义于 `index.html` 内 `solarTerms[]` 数组）包含以下字段：

| 字段 | 说明 |
|------|------|
| `name` | 节气名称（如 "立春"） |
| `date` | 日期范围（如 "2月3日-5日"） |
| `season` | 所属季节（`spring` / `summer` / `autumn` / `winter`） |
| `shortDesc` | 物候三候短描述 |
| `custom` | 习俗关键词 |
| `longDesc` | 节气简介 |
| `content` | 完整文案（含天文、物候、习俗、饮食、养生） |
| `poem` | 关联古诗词（含出处） |

## 开发说明

### 本地运行

```bash
# 无需安装任何依赖，直接打开即可
open index.html
# 或使用本地服务器（推荐，避免图片加载的路径问题）
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

### 技术要点

- **零外部依赖** — 不使用任何 CDN、字体库（`font-family` 回退至系统自带楷体/宋体/衬线体）、第三方库或框架
- **所有资源本地部署** — 图片、文案全部内置于项目目录
- **纯内联架构** — 全部 HTML/CSS/JS 位于单个 `index.html` 文件中，易于部署与修改
- **IntersectionObserver** — 用于驱动滚动入场动画，无显式性能开销
- **节气自动识别** — 节气钟模块中的 JavaScript 根据当前日期自动匹配并高亮显示对应节气

# 岁时纪 · 时光里的东方节律

以二十四节气为主题的非遗文化交互视觉网页：从 **立春** 到大寒，用一页之内的时序浏览呈现节气的天文、物候、民俗、饮食与诗词，并以「节气非遗名录」「七十二候」「节气钟」三块专题构成文化叙事。

> 二十四节气于 2016 年列入联合国教科文组织人类非物质文化遗产代表作名录。

## 一、技术与视觉特征

- **零框架**：HTML5 + CSS3 + 原生 ES6，无第三方库、无 CDN、无字体库（字体回退至系统楷体／宋体／衬线体）。
- **结构分层**：`index.html`（结构）、`css/style.css`（样式与动效）、`js/app.js`（数据与交互）三层分离，便于阅读与维护。
- **节气时刻推算**：以太阳视黄经低精度公式迭代求解 24 个节气时刻，据此刻画「当前节气／上一节气／下一节气」与倒计时。
- **视觉语言**：宣纸质感底色、低饱和大地色系（赭石／琥珀金／青铜）、留白与渐入动效，四时以卡片与背景图分区呈现。
- **响应式**：桌面 4 列 → 平板 3 列 → 手机 2 列的节气网格；节气钟改为侧边抽屉，移动端纵向重排。

## 三、页面模块

| 模块 | 说明 |
|---|---|
| **首屏视差** | 全屏背景 + 渐变压暗层 + 标题入场动画，滚动时渐隐 |
| **节气总说** | 引言，点出节气作为「东方时间观」的定位 |
| **四季卡片** | 立春／立夏／立秋／立冬四张横卡，依次入场 |
| **24 节气网格** | 由数据驱动渲染，含节气名、常见日期区间、三候短述、习俗标签与倒计时 |
| **全屏沉浸阅览** | 点击卡片进入，展示完整文案与诗词；支持左右切换、键盘 ← →、Esc 关闭、顶部缩略图导航 |
| **节气非遗名录** | 11 项与节气直接相关的民俗类非遗，双图层图片 + 悬停 3D 展开 + 详情 |
| **花信风 · 七十二候** | 24 节气 × 3 候 = 72 张物候卡片，响应式网格 |
| **节气钟（侧边抽屉）** | 右侧挂件唤起：实时时钟、干支纪年月日、当前节气、倒计时、前后节气提示，可进入全屏屏保 |
| **全屏屏保** | 十二时辰 + 大字时钟 + 节气名 + 干支日期，点击／Esc 退出 |
| **返回顶部** | 右下角固定按钮，平滑滚动 |

## 四、数据与算法说明

- `solarTerms[]`：24 条记录，字段 `name / date / season / shortDesc / custom / longDesc / content / poem`。
- `heritageItems[]`：11 条非遗记录，字段 `name / desc / detail`，对应 `custom-image/习俗{n}.1.webp` 与 `.2.webp`。
- `getTermDate(year, i)`：由太阳视黄经以牛顿迭代逼近节气时刻；`getCurrentSolarTermInfo()` 返回当前、上一与下一节气。
- **节气日期口径**：网格卡片上的「2 月 3 日—5 日」为常见日期区间；节气钟显示的节气时刻来自上述推算，两者用途不同，不构成同一数据的两套结论。
- **干支说明**：节气钟显示的「干支纪年／月／日」为界面装饰性近似换算（月柱按公历月份换算，未按交节分界；日柱以 2000-01-01 为基准日推算），**不是农历月日**，也不用于任何文化结论的核算。

## 五、本地运行与部署

```bash
# 方式一：本地静态服务器（推荐，避免 file:// 下的部分限制）
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 方式二：直接双击 index.html
```

- 所有资源使用相对路径（`css/` 内引用 `../image/…`），可直接部署到任意静态托管。
- 推荐使用 HTTP(S) 环境：全屏沉浸与屏保依赖安全上下文的部分能力。

## 六、素材与授权

- 24 张节气插画、24 张节气氛围背景、11 项非遗实景图：由本团队与协作者共同创作／拍摄／整理，**具体署名与授权范围另见项目材料中的《第三方资源说明》**。
- 页面未引入任何第三方代码、字体、图标库或评论组件；不使用外部请求，断网后页面主体仍可完整浏览。
- 节气文案、七十二候原文与诗词均按公开资料整理，出处见 `content/` 目录内素材文件。
